GETTING STARTED

A little curiosity is all you need.

This website brings HTML learning tools into one collection. No student accounts, subscriptions or external assets are needed for the included CircuitLab tool.

Find a tool and start exploring

  1. Open the toolbox on the homepage. Search by topic or choose a subject.
  2. Choose Open tool. CircuitLab opens as a full-page workbench.
  3. On a classroom TV, use landscape mode and the tool’s Fullscreen button. Tap or drag components, then connect their terminal circles.
  4. Run the circuit and compare your predictions with the measurements.

Download once. Explore offline.

Choose ↓ Download on a tool card to save a self-contained HTML file. Open that file in a current browser without an Internet connection. The CircuitLab download includes its styles, symbols and solver in one file. A managed browser may restrict local files; in that case run a local web server.

Your personal library

Use Add HTML file on the homepage to keep a self-contained HTML tool in this browser. Files are saved in the browser’s IndexedDB database, not on the public website. Reloading the same website in the same browser retains them. Clearing site data, private browsing limits or storage eviction can remove them, so keep original copies.

The isolated viewer supports inline scripts and embedded styles/images. It restricts external resources and prevents access to the library’s data. Tools that need external files, browser storage, workers or remote APIs may not work there. Download them and open their original files separately when appropriate. Do not import files you do not trust.

40 simple questions

Question 1 is a teacher demonstration with one wire left to connect. The other 39 questions teach circuit symbols and diagrams. Start or Run begins a two-minute attempt. There are no numerical settings or calculation targets.

Show answer unlocks with 40 seconds left and opens a labelled picture immediately. There are no dances or punishments. Correct circuits earn a congratulations popup and unlock Next; Back is always available. Each student question begins with a clean board.

Classroom progress

CircuitLab stores its board and classroom scores locally. There is no shared online student database. Public catalog entries are available to everyone; personal imports and CircuitLab progress stay with a browser profile and website address.

Teacher resources

Start with the 45-minute activity guide, then use the tested example circuits to check expected readings. CircuitLab uses labelled DC steady-state models, not a full transient SPICE simulator.

Publish your own tool

Personal imports are private to this device. To add a tool to the public catalog, follow the publishing workflow. There is no unauthenticated public upload endpoint.

Hint unlocks after 30 seconds (1 minute 30 seconds left). Show answer unlocks with 40 seconds left. Both stay available after time runs out; completed questions allow review.

Need more time? Restart beside the clock gives two more minutes and keeps the circuit. Help countdowns restart too.
